# Delivez Postman Workspace

This directory contains separated, ready-to-import Postman collections and environments organized by target environment:

## 📂 Folders

- **[`local/`](./local)**: Configured for Local Development (`http://localhost:4000/api/v1`). Includes all 4 collections, local environment, and `delivez_local_postman.zip`.
- **[`production/`](./production)**: Configured for Production/Staging (`http://40.81.244.167:3012/api/v1`). Includes all 4 collections, production environment, and `delivez_production_postman.zip`.

---

## 📦 Zip Bundles for Quick Import

- **Local Bundle**: `postman/local/delivez_local_postman.zip`
- **Production Bundle**: `postman/production/delivez_production_postman.zip`
